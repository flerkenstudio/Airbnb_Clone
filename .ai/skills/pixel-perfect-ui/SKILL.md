# Skill: Pixel-Perfect UI

Before changing CSS:
1. Identify the reference element.
2. Measure/estimate its position, dimensions and spacing.
3. Compare typography and visual properties.
4. Implement the smallest change.
5. Re-check the whole surrounding layout.

Priority:
1. Geometry
2. Typography
3. Spacing
4. Colors/borders
5. Icons
6. Motion

Do not compensate for a wrong parent layout with arbitrary child offsets.
