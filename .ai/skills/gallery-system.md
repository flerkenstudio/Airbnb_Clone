# Skill: Gallery System

Use one source of truth for gallery images and their ordering.

Required behavior:
- Photo Tour entry from hero image and "Show all photos".
- Lightbox entry from gallery photos.
- Previous/next navigation.
- Left/Right keyboard navigation.
- Escape close.
- Correct current-image state.
- Overlay scroll locking.
- Focus management.
- Smooth but reference-consistent transitions.

Keep gallery state separate from listing content.
