# Skill: Accessibility

For every interactive element:
- Use semantic HTML.
- Make keyboard operation possible.
- Provide an accessible name where an icon is the only visual label.
- Preserve visible focus.
- Maintain logical focus order.

For overlays:
- Treat Lightbox as a dialog-like interaction.
- Move focus into the overlay.
- Keep focus within the active overlay as appropriate.
- Restore focus to the triggering element after close.
- Close on Escape.
- Prevent background interaction while active.
