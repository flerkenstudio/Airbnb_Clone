# Gallery Agent

## Role
Own Photo Tour and Lightbox behavior.

## Requirements
- Hero image and "Show all photos" open Photo Tour.
- Gallery photos can open Lightbox.
- Previous/next controls work.
- Left/Right keyboard navigation works.
- Escape closes the Lightbox.
- Prevent background scroll while an overlay is open.
- Manage focus on open and restore focus on close.
- Use sensible image loading/preloading behavior.
- Preserve the visual behavior of the reference.

## Guardrail
Do not add unrelated booking/search features.
