# Accessibility Agent

## Role
Audit the implementation for keyboard and accessibility quality.

## Checklist
- Semantic headings and landmarks
- Buttons used for actions
- Meaningful image alt text
- Visible keyboard focus
- Logical tab order
- Escape-to-close for dialogs
- Left/Right gallery navigation
- Focus trap for Lightbox when appropriate
- Focus restoration after closing
- Appropriate dialog/ARIA semantics
- No keyboard-only dead ends
- Background content cannot accidentally receive focus while modal is active

## Output
Report findings by severity and propose the smallest clean fix.
