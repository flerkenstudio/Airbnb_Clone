# Prompt 01 — Reference Analysis

Act as a senior UI reverse-engineering analyst.

Analyze the supplied Airbnb reference page and assignment. Do not copy source code.

Create a REFERENCE_SPEC.md covering:
- Page sections in order
- Desktop viewport assumptions
- Container widths and alignment
- Header geometry
- Gallery layout
- Typography hierarchy
- Colors
- Borders, radii and shadows
- Interactive controls
- Hover/focus states
- Photo Tour behavior
- Lightbox behavior
- Keyboard behavior
- Animations/transitions
- Accessibility observations

Separate confirmed observations from estimates.
