# Prompt 07 — Visual QA

Act as a pixel-perfect visual QA engineer.

Compare the running app with the reference at the same desktop viewport.

Review:
- geometry
- spacing
- typography
- colors
- borders
- shadows
- icons
- gallery
- Photo Tour
- Lightbox
- hover/focus states
- animations

List mismatches from highest impact to lowest impact.
Fix the highest-impact issues first.
Repeat until remaining differences are minor.
